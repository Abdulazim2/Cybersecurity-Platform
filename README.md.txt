## About the Project

The **AI-Based Industrial Cybersecurity Monitoring Platform** is a centralized security monitoring solution designed to detect abnormal behavior and potential cyber threats across multiple industrial environments.

The platform aims to leverage Artificial Intelligence and Machine Learning to analyze industrial security data, identify suspicious activities, and help security teams monitor and respond to potential cyber incidents.

It is designed to support multiple companies and factories through centralized monitoring, role-based access control, security analytics, and explainable AI-based predictions.

## Key Objectives

- Monitor cybersecurity activities across industrial environments.
- Detect suspicious behavior and potential cyberattacks.
- Analyze system, network, IoT, and authorization logs.
- Provide centralized monitoring for multiple companies and factories.
- Generate security alerts and historical incident records.
- Improve threat visibility through explainable AI techniques.

## Main Features

- Secure authentication using JWT.
- Role-Based Access Control (RBAC).
- Multi-company and factory management.
- Security dataset uploading and validation.
- CSV and JSON data ingestion.
- Network event monitoring.
- Security notifications and alerts.
- Dashboard statistics and security analytics.
- AI prediction integration architecture.

## Supported Security Datasets

The platform is designed to process four main categories of industrial security data:

| Dataset | Description |
|---|---|
| System Logs | Operating system and application activities |
| Traffic Logs | Network traffic and communication events |
| IoT Behaviour Logs | Industrial IoT device activities |
| Authorization Logs | Authentication and access-control activities |

## AI & Machine Learning

The proposed AI pipeline includes:

- Random Forest
- XGBoost
- Explainable AI using SHAP

The intended classification categories are:

- Normal
- Suspicious
- Attack

*The machine learning models and their integration are part of the project's planned development workflow.*

## Project Architecture

The platform follows a modular architecture:

1. **Data Collection:** Receives industrial security datasets.
2. **Data Processing:** Validates, normalizes, and prepares uploaded data.
3. **Backend API:** Handles authentication, authorization, data management, and business logic.
4. **AI Detection Engine:** Processes security data and generates predictions.
5. **Dashboard:** Presents monitoring information, statistics, predictions, and alerts.
